Stream-Flaflix

A private dashboard for your media server.

Stream-Flaflix is self-hosted software for Jellyfin and Emby. It brings invitations, watch history, live sessions, requests and encrypted offsite backups into one dashboard that runs on the operator's own hardware.

Why this page exists

This is the public application page for the optional Google Drive backup integration. Stream-Flaflix uses Google Drive only to keep encrypted backup copies in a folder selected by the instance operator. The dashboard itself is private and available only to that operator.

Privacy policy

This instance is privately operated. It is not a public media service.
